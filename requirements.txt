# against on Python 3.14 (live Token Factory runs, live SSE, full test
# suite). The original pins here were guesses written before anything ran:
# among other problems pydantic 2.10.5 has no Python 3.14 wheel, so a
# container build fell back to compiling pydantic-core from Rust source
# and failed.
